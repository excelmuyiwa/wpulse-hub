Player setup

Follow the steps in order. It takes about 5 minutes.

  1. Download the extension

    Click the button to download the WPulse extension (a .zip file).

    Download extension

    Version: 1.2.0 · Updated: 28 Oct 2026

    Screenshot: the downloaded zip file in your Downloads folder

  2. Unzip to a folder that stays in place

    Right-click the zip and choose Extract All. Keep the extracted folder somewhere permanent, such as Documents. Do not move or delete it afterwards, or the extension will stop working.

    The zip also contains a file called HOW TO INSTALL.txt with the same steps.

    Screenshot: the unzipped WPulse folder in its permanent location
    Screenshot: the extracted folder showing the inner 'WPulse Extension' folder

  3. Load it into Chrome

    In Chrome, type chrome://extensions in the address bar and press Enter. Then:

    1. Turn on Developer mode (top right).
    2. Click Load unpacked.
    3. Open the extracted folder, then select the inner folder called WPulse Extension (the one that contains manifest.json), not the outer folder.

    Tip: if Chrome says "Manifest file is missing", you picked the outer folder. Go one level deeper.

    Screenshot: chrome://extensions with Developer mode on and the Load unpacked button

  4. Find your install ID

    Open Woogles in a game, then click the WPulse icon in the Chrome toolbar. Your install ID is shown in the popup. (Tip: click the puzzle-piece icon and pin WPulse if you cannot see it.)

    Screenshot: the WPulse popup showing the install ID

  5. Send your install ID and wait for approval

    Send your install ID directly to the organizer. You can use any of these three contacts:

    • WhatsApp: +234 9065728333
    • Telegram: @ExcelMuyiwa
    • Discord: excelmuyiwa.

    Send these three things in one message: your install ID, your name, and your Woogles username(s).

    Then wait to be approved. The organizer will confirm when you are set.

    Screenshot: example message with the install ID (optional)

  6. If Chrome shows a developer mode notice

    When Chrome starts, it may show a message about disabling developer mode extensions. Dismiss it. Do not remove the extension.

    Screenshot: the Chrome startup notice and where to dismiss it

How to update WPulse

When a new version is released, follow these steps.

  1. Download the new zip

    Download it from the Player setup section of this page. Check the Version line to make sure it is newer than yours.

  2. Replace the old folder

    Close your Woogles tab. Delete the old extracted folder, then extract the new zip to the same place as before (the same folder location).

  3. Refresh the extension

    Open chrome://extensions and click the refresh button (the circular arrow) on the WPulse card. Do not remove the extension.

    Screenshot: the WPulse card on chrome://extensions with the refresh (circular arrow) button

  4. Reload Woogles

    Reload your Woogles tab.

    Your install ID stays the same, so you do not need to be approved again.
